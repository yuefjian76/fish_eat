# Product Description -- 鱼吃鱼 (Fish Eat Fish)

## What Is This?

鱼吃鱼是一款单人的 Phaser.js 3.x HTML5 游戏，玩家控制一条鱼吃更小的鱼、与 AI 敌人战斗、升级、解锁技能。

## Core Features

### 游戏机制

- **吃鱼规则** — 玩家必须比目标大 20% 以上才能吃掉
- **属性克制** — 剪刀石头布式（鲨鱼 > 小鱼 > 虾 > 鲨鱼）
- **升级** — 提升体型、解锁技能、触发漂流瓶效果
- **难度** — 简单/普通/困难，敌人数量和 AI 侵略性递增
- **玩家体型** — 玩家为基础体型的 2 倍（便于识别）

### 操控方式

| 输入 | 动作 |
|-----|------|
| 方向键 ↑↓←→ | 移动 |
| Shift | 加速 |
| Q | 撕咬技能（伤害） |
| W | 护盾技能（无敌） |
| E | 加速技能（速度提升） |
| R | 治疗技能（回血） |
| 鼠标 | 替代移动方式（点击移动） |

### 特殊鱼行为（5种）

| 鱼类型 | 特殊行为 | 效果 |
|--------|---------|------|
| 鳗鱼 (Eel) | 冲刺攻击 | 短距离高速冲刺造成伤害 |
| 章鱼 (Octopus) | 隐身 | 短暂隐身，无法被敌人检测 |
| 海马 (Seahorse) | 逃跑 | HP 低时主动逃离玩家 |
| 水母 (Jellyfish) | AOE | 周期性释放范围伤害 |
| 灯笼鱼 (Anglerfish) | 远程攻击 | 发射投射物攻击玩家 |

### 波次系统

游戏使用动态波次系统：
- **Calm** — 平静期，刷怪间隔 8 秒
- **Surge** — 高峰期，刷怪间隔 4 秒
- **Peak** — 峰值，刷怪间隔 2 秒

波次状态循环：calm → surge → peak → calm

### 技能系统

| 技能 | 快捷键 | 冷却 | 效果 |
|------|-------|------|------|
| 撕咬 | Q | 5s | 对目标造成伤害 |
| 护盾 | W | 15s | 3秒无敌，免疫伤害 |
| 加速 | E | 12s | 移动速度 +50%，持续 5s |
| 治疗 | R | 20s | 恢复 30% HP |

### 成就系统

15 个里程碑成就：
- 吃掉 10/50/100 条鱼
- 达到等级 5/10/15/20
- 获得 1000/5000/10000 分数
- 生存 1/5/10 分钟
- 击败 5/10/20 鲨鱼
- 其他特殊挑战

### 漂流瓶系统

升级时有概率触发漂流瓶效果（好/坏随机）：
- **好的效果** — 双倍经验、护盾、回血
- **坏的效果** — 减速、虚弱、召唤敌人

### 商店系统

游戏内商店可购买升级：
- 永久增加 HP 上限
- 永久增加伤害
- 永久增加移动速度
- 永久增加经验获取

### 数据持久化

- **认证** — localStorage 认证会话
- **用户数据** — localStorage 存档（分数、等级、设置）
- **会话** — 跨页面刷新保持登录状态

#### 死亡演出（feat-052）

血量归零后不再立刻切到结算页，先播放约 1.35 秒的死亡演出：

| 阶段 | 时长 | 表现 |
|------|------|------|
| 定格 | 150ms | 全场冻结（敌鱼静止）、白屏闪光、镜头震动 |
| 冲击 | 700ms | 镜头推进到玩家身上（zoom 1.0 → 1.3）、玩家淡出、颗粒爆散、"GAME OVER" 浮现 |
| 淡出 | 500ms | 画面淡出至黑，进入结算页 |

- 演出期间玩家无法操作，敌鱼也无法再造成伤害。
- 结算用的击杀数/生存时间在**死亡瞬间**定格，不含演出时长。
- 数值可在 `src/config/death_sequence.json` 调整。

#### 低血量警告（feat-053）

血量低于 30% 时开始给出渐进式警告，越危险越强烈：

| 血量比例 | 表现 |
|---------|------|
| ≥ 30% | 无提示 |
| 30% ~ 18% | 屏幕四周红色暗角，红光随危险度加深 |
| ≤ 18%（危险） | 红光开始脉冲呼吸、屏幕上方显示 `危险` 文字、播放心跳音（越危险越快） |

- 暗角只覆盖屏幕边缘，画面中心保持清晰，不影响辨认敌鱼。
- 回血（脱战回血 / 道具）把血量拉回阈值以上后，所有提示立即消失。
- 死亡演出开始时会清空低血量警告，避免演出期间残留红光。
- 数值可在 `src/config/low_health.json` 调整（阈值、强度曲线、脉冲周期、心跳间隔、文字）。

### Boss 战

三只阶段性 Boss，分别在 5 / 8 / 11 级出现（每次升级检查，已经击败过的不会重复出现）：

| Boss | 出现等级 | 特点 |
|------|---------|------|
| 大王乌贼 | 5 | 触手拍击；半血后进入二阶段，喷墨遮挡视野 |
| 鲨鱼之王 | 8 | 冲刺撞击；二三阶段召唤小鱼、眩晕玩家 |
| 海龙 | 11 | 火焰吐息；二三阶段地震、召唤 |

战斗规则：

- **1v1**：Boss 登场时现有敌鱼四散逃离，战斗期间不再刷新新的敌鱼；击败后恢复正常刷怪。
- **入场**：登场前 3 秒全屏预警（Boss 名字），Boss 从屏幕外冲入 / 从下方升起。
- **血条**：顶部显示 Boss 名字与实时血量，Boss 头顶也有一条小血条。
- **走位窗口**：Boss 的追击速度（120~150）低于玩家（200），近战范围（80~90）小于 Q 撕咬的实际射程（约 120）。
  保持距离输出可以安全磨血；贴脸不动会被逐次击中（18~26 伤害 / 1.4~1.6 秒）。
- **节奏实测**：5 级乌贼战 10 次撕咬、约 27 秒击杀（走位打法，玩家几乎不掉血）；站桩不动约 25 秒会被打死。
- 数值全部在 `src/config/fish.json` 的 Boss 条目中调整（`baseHp` / `damage` / `attackInterval` / `attackRange` / `visionRange`）。

## 约束

- **最大体型比例** — 玩家只能吃比自己小 20% 的鱼

### 成长曲线与难度阶梯（feat-055 实测调整）

- **玩家体型成长**：逐级倍率由 `levels.json.sizeGrowth` 定义（1.5 / 1.5 / 1.4 / 1.3 / 1.25 / 1.2 / 1.15 / 1.12 / 1.1 / 1.08），
  Lv1→Lv11 累计约 **9.4 倍**（30 → 273）。此前写死每级 ×1.5 复利（57.7 倍），
  导致 Lv4 之后所有普通敌鱼都能被吃、接触伤害永远不可能触发。
- **敌人尺寸**：按玩家体型**开方**缩放（Lv11 ≈ 3.02×），保证任意等级都存在：
  - 可吃档（小于玩家 1/1.2）
  - 威胁档（大于玩家 1.2×，如 Lv11 的巨型水母 361 vs 玩家 273）
- **难度爬升**不再放大敌人**尺寸**，而是放大血量/经验（存活时间最多 +30%、敌人等级差 +15%/级）。
  尺寸随难度上涨会让唯一可吃的鱼越过判定，玩家将无法成长。
- **Boss** 尺寸同样随玩家缩放，始终显著大于玩家（≥1.5×），不会被"一口吃掉"。
- **接触伤害**单次不超过玩家最大生命的 25%，避免被大鱼贴一下即死。
- **最小支持分辨率** — 800x600
- **浏览器要求** — WebGL 支持
- **最大敌人数量** — 根据难度动态调整

## 世界坐标与深度系统（ScrollingWorld）

### 世界尺寸

- **尺寸**: 20000 × 20000 像素
- **出生点**: (10000, 14000) — 深海区域，向上可探索至浅海

### 深度区域（5 个）

玩家沿 worldY 轴移动时，背景颜色和装饰类型随深度变化：

| 区域 ID | worldY 范围 | 名称 | 颜色基调 | 主要装饰 |
|---------|------------|------|---------|---------|
| `surface` | 0 ~ 2000 | 浅海 | 亮青绿 | 阳光光柱、小气泡 |
| `shallow` | 2000 ~ 4000 | 珊瑚礁 | 青蓝 | 珊瑚群 |
| `mid` | 4000 ~ 8000 | 中层 | 深蓝 | 海草、礁石 |
| `deep` | 8000 ~ 12000 | 深海 | 暗蓝 | 大岩石、暗礁 |
| `abyss` | 12000 ~ 20000 | 深渊 | 接近黑 | 发光水母轮廓 |

### 深度雾效

- worldY < 12000: 无雾
- worldY = 12000 ~ 20000: 雾 alpha 从 0 线性增至 0.65
- 雾色: `#010818`（深蓝黑）

### 视差层（3 层）

| 层 | scrollFactorX | 视觉效果 |
|----|--------------|---------|
| 背景层 | 0.08 | 最慢，几乎静止 |
| 中层 | 0.25 | 中速 |
| 前景层 | 0.50 | 快速，与玩家速度接近 |

### 方向语义

- **向上 (worldY 减少)**: 从深海进入浅海，颜色变亮，装饰从发光水母变为阳光光柱
- **向下 (worldY 增加)**: 从浅海进入深海，颜色变暗，装饰从珊瑚变为发光水母
- **向左/向右**: 视差效果产生卷轴感，装饰类型由 chunk 种子决定（同一位置可复现）

## 性能目标

- 游戏加载: <3 秒
- 帧率: 60 FPS
- 碰撞检测: O(n) 优化
- 敌人 AI: 每帧 <1ms
